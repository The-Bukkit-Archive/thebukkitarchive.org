# Objective
The goal of the Bukkit Archive is to archive as much Minecraft multiplayer-related content as possible. The end goal is to provide downloads for plugins, server software, and client-side mods which interact with servers across the history of Minecraft.

# Contributing
To contribute, please open a GitHub issue containing a link to the plugin you would like archived. If you would like to contribute yourself, see the `_posts` folder and copy an existing post. The post must follow this exact format: `YYYY-MM-DD-[PLUGIN|SERVER|CLIENT|TOOL|]-[SOFTWARE-NAME](-BUILD NUMBER)`. The build number is optional if it is not present or if there are multiple builds in a post.
